# Shinta Selviriani — Taxation Portfolio

A responsive personal CV/portfolio website with an elegant finance theme:
cream + dark green + beige.

## Files
- index.html — main website
- style.css — design and responsive layout
- script.js — scroll/reveal interactions

## Quick start
1. Keep all three files in the same folder.
2. Open `index.html` in Chrome/Edge.
3. To add your profile photo later, replace the `YOUR PHOTO` block in `index.html` with an `<img>` tag.
4. Certifications and WhatsApp can be added later without changing the overall design.

## Deployment
The folder can be uploaded to any static hosting service such as GitHub Pages, Netlify, or Vercel.
