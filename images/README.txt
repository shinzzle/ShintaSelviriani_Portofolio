# Folder Foto Portofolio Shinta Selviriani

Simpan foto-foto dokumentasi kegiatan, sertifikat, momen penghargaan, dan foto profil Anda di folder ini (`images/`).

### Rekomendasi Format & Nama File:
1. `profile.jpg` -> Foto profil utama di bagian Hero.
2. `kpp-pratama-1.jpg` -> Dokumentasi Tax Volunteer di KPP Pratama Taman Sari.
3. `teazzi-event.jpg` -> Dokumentasi TEAZZI Student Brand Manager.
4. `hima-binus-1.jpg` -> Dokumentasi HIMA BINUS / Head of Region.
5. `ldk-hima.jpg` -> Dokumentasi LDK-A HIMA 2027.
6. `unpam-tax-competition.jpg` -> Foto utama Juara 1 UNPAM Tax Competition.
7. `unpam-trophy.jpg` -> Foto piala / panggung penghargaan UNPAM.
8. `unpam-presentation.jpg` -> Foto saat presentasi karya video.
9. `tax-youth-semifinal.jpg` -> Foto kompetisi Tax Youth Semifinalist.
10. `winner-fyp-recap.jpg` -> Foto pemenang video recap FYP B28.
11. `sertifikat-unpam-juara1.jpg` -> File scan sertifikat Juara 1 UNPAM.
12. `sertifikat-riset-zenodo.jpg` -> File sertifikat publikasi riset ilmiah.
13. `sertifikat-relawan-pajak.jpg` -> File sertifikat Relawan Pajak DJP.

Setelah menaruh file foto di folder ini, buka file `index.html` dan ganti `src="..."` sesuai nama file Anda (contoh: `src="images/unpam-tax-competition.jpg"`).
